# jerry-term

Interactive terminal CLI for Jerry AI agent.

## Installation

```bash
npm i -g jerry-term
```

## Development

```bash
# Install dependencies
pnpm install

# Build
pnpm --filter jerry-term build

# Test locally
cd packages/jerry-term && npm link
jerry-term --version
```

## Usage

```bash
jerry-term --version    # Print version
jerry-term              # Start interactive REPL (coming soon)
```
